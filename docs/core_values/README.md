This directory centralizes documents that track alignment with `CORE_VALUES.md`.

- `status.md` – canonical compliance status with code references and follow-up actions (reviewed 2026-07-21).
- `../security/CAPABILITY_ATTENUATION.md` – least-privilege child-config and resource-ceiling inheritance contract.

- Benchmarks and performance analyses live alongside this index; cross-link them here as they are refreshed.

When adding new host capabilities or architectural changes, update `status.md` and link any supporting deep-dive document from this index.
